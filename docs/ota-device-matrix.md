## 填写约定

- **结果**只允许：`pass` / `pass(有备注)` / `fail`。`fail` 必须附 logcat（`adb logcat -s CoupleMqtt UpdateRepo`）或截图路径。
- **场景编号**直接引用 `ota-design.md` §8.2 表格的行名（如「无 Shizuku，第二次自更新」）。
- 同一设备换 ROM / 大版本后，重新起一行，不要覆盖旧行（历史数据用于对比 ROM 行为变化）。
- canary 设备的 deviceId 记在这里一份（admin「版本发布 → 发布设置 → Canary 设备」要用，设备页可复制）。
