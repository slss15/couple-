# Android 单人记账与界面更新（2026-11-07）

## 范围与边界

- Stitch 压缩包只作为视觉参考；其中的说明、示例金额、人物与双人记账流程不作为业务要求。
- 使用现有 Compose 主题与组件、Room DAO、DataStore 设置。没有新增后端接口或修改接口契约。借贷账户改版将本机 Room 升至 v9，保留旧表并提供 v8→v9 非破坏迁移。
- 新默认主题为「鸡毛和小白」奶油/橘色；已有明确保存的主题和启动页不被覆盖。
- 账本仍是个人账本，没有共同小金库、AA 分摊、付款人、向 TA 同步、双人总预算、共同账户分组或双人配比。

## 可用流程

1. **记账**：金额（计算器）→ 收支类型 → 账户 → 一级分类 → 细分子类 → 日期/备注确认。转账独立为五步，不选择分类；不计收支、不计预算。没有一页堆全部步骤的极速版。
2. **借贷账户**：在“我的账户”添加借出/借入类型，点进账户按个人或平台分类；每个人/平台有独立借款、还款、待收/待还、逾期及结清明细。收入分类“还钱·收回借款”选择借出账户与借款人；支出分类“还钱·归还借款”选择借入账户与还款对象/平台。创建借款时可选择实际资金账户同步记录本金，也可选择历史补录不生成资金记录。
3. **纪念日**：新增/编辑/删除；保留公历、农历、闰月和重复规则。当天打卡去重；最近待到来的事件可调整神秘惊喜准备进度。
4. **旅行计划**：设置名称/目的地、关联个人账户与目标金额。攒钱进度来自账户真实余额；余额为负时明确提示，账户被删除时提示重新选择，不能伪造为已有储蓄。
5. **启动与排序**：设置里选择默认页（未设置时为动态）；隐藏或禁用的入口不允许选为新启动页。Tab 和账户顺序统一长按浮动拖拽：浮起与阴影、其他项自动让位、边缘自动滚动、松手一次保存；移除上移/下移按钮。账户排序同步作用于记账时的账户顺序。取消拖拽不保存，保存失败恢复原顺序。
6. **后台**：Shizuku 静默安装和一键豁免沿用现有实现；静音前台服务与最近任务可见性分别设置。通知权限未同意时不自动开启通知常驻；通知上可以关闭连接。回到前台时按用户开关重试服务，用户关闭后不自动复活。

## 个人数据说明

打卡、惊喜进度、旅行目标和排序仍在本机 DataStore 保存。借贷与偿还明细迁入本机 Room，与对应资金账目在同一事务中保存/撤销，避免漏记、重复和并发覆盖；不是双人同步数据。旧六段竖线/JSON 借贷记录按借入/借出导入对应账户，保留历史已还及还款明细，不补造历史收支，原字符串留作备份。借贷本金不计日常收支/预算，实际资金账户余额会变化；总资产包含借出待收回并扣除借入待还。清除应用数据会清除这些本机信息。

## 验证与人工检查

自动回归覆盖金额精度与溢出、旧借贷兼容、连续/并发还款、编辑期间的新还款不丢失、账户/Tab 排序、启动页解析、旅行真实余额和打卡去重。

2026-11-07 验证结果：264 项 JVM 单元测试、18 项 Android 14 模拟器测试全部通过（0 失败、0 跳过）。模拟器回归覆盖：收入收回个人借款、支出归还平台借款、同名个人/平台的独立明细、真实 v8→v9 数据库迁移、现金与还款进度事务提交/撤销、并发还款与重复保存、删除账户与新建借贷并发、长按拖拽/取消/保存失败恢复、手指停留边缘自动滚动，以及银行 logo 原色与无统一圆底。

资金账户删除后允许修改借贷名称/备注，但禁止改动关联本金；借贷账户删除与明细检查使用同一事务，还钱保存时再次核实借贷和实际资金账户有效性。金额输入复用精确到分的解析器，拒绝截断小数或 Long 溢出。

默认 arm64 Debug APK 构建成功，已核对包内原生库仅含 arm64-v8a。调试包在模拟器冷启动成功，未出现 AndroidRuntime 崩溃日志；这不等于已完成真机验证。

真机需要补测：
- 小屏、大字、旋转及输入法弹出时六步/五步向导能完整滚动和返回。
- 新增账户后继续记账；补记日期；转账双方不能相同。
- 农历生日、闰月、当天打卡、已过去的一次性事件、旅行账户删除。
- 通知拒绝/允许、常驻连接关闭、锁屏、划掉最近任务、重启、OEM 省电限制及 Shizuku 未运行/未授权/已授权。

最近任务可见性不等于 OEM 卡片加锁或绝对保活。本次未连接真机，不能声称已经验证长期后台存活；不绕过系统强行停止或用户的关闭选择。

原项目路径含中文，Windows AGP 路径检查和测试类加载可能失败。本次通过工作区外的 ASCII 路径 junction 指向同一个 app 目录进行构建，没有搬动源文件，也没有提交本机路径或 SDK 配置。

### 账户图标与拖拽补充

银行 logo 直接显示现有 VectorDrawable 原始填色，不加颜色滤镜，不再套统一主题色圆底。现金、支付宝、微信的现有 iconfont 素材本身为单色字形，保持中性前景（不是彩色原图）；不通过简单滤镜伪造多色品牌素材。

已由用户确认借出/借入账户、收入/支出还钱入口、个人/平台分类及独立明细。利息、手续费、核销、双人同步不在此次需求范围。
