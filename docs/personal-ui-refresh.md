# Android 单人记账与界面更新（2026-11-07）

## 范围与边界

- Stitch 压缩包只作为视觉参考；其中的说明、示例金额、人物与双人记账流程不作为业务要求。
- 使用现有 Compose 主题与组件、Room DAO、DataStore 设置。没有新增后端接口，没有修改接口契约或 Room 数据库版本。
- 新默认主题为「鸡毛和小白」奶油/橘色；已有明确保存的主题和启动页不被覆盖。
- 账本仍是个人账本，没有共同小金库、AA 分摊、付款人、向 TA 同步、双人总预算、共同账户分组或双人配比。

## 可用流程

1. **记账**：金额（计算器）→ 收支类型 → 账户 → 一级分类 → 细分子类 → 日期/备注确认。转账独立为五步，不选择分类；不计收支、不计预算。没有一页堆全部步骤的极速版。
2. **借贷**：账户列表或账户详情 → 信用与负债 → 新增借入/借出。可填对方、用途、关联账户、总金额、历史已还金额、约定日期；分次记录偿还日期、金额与备注，查看待还/待收、逾期和结清状态。
3. **纪念日**：新增/编辑/删除；保留公历、农历、闰月和重复规则。当天打卡去重；最近待到来的事件可调整神秘惊喜准备进度。
4. **旅行计划**：设置名称/目的地、关联个人账户与目标金额。攒钱进度来自账户真实余额；余额为负时明确提示，账户被删除时提示重新选择，不能伪造为已有储蓄。
5. **启动与排序**：设置里选择默认页（未设置时为动态）；隐藏或禁用的入口不允许选为新启动页。Tab 顺序即时保存；账户页上移/下移改变展示顺序和记账时的账户顺序。
6. **后台**：Shizuku 静默安装和一键豁免沿用现有实现；静音前台服务与最近任务可见性分别设置。通知权限未同意时不自动开启通知常驻；通知上可以关闭连接。回到前台时按用户开关重试服务，用户关闭后不自动复活。

## 个人数据说明

借贷备忘、偿还明细、打卡、惊喜进度、旅行目标和排序在本机 DataStore 持久保存；不是双人同步数据。旧的六段竖线借贷记录兼容读取，修改后保存为 JSON。账户关联只是归属/读取余额，不自动生成账目；实际资金变化仍需另记一笔，避免重复影响个人余额。清除应用数据会清除这些本机信息。

## 验证与人工检查

自动回归覆盖金额精度与溢出、旧借贷兼容、连续/并发还款、编辑期间的新还款不丢失、账户/Tab 排序、启动页解析、旅行真实余额和打卡去重。

真机需要补测：
- 小屏、大字、旋转及输入法弹出时六步/五步向导能完整滚动和返回。
- 新增账户后继续记账；补记日期；转账双方不能相同。
- 农历生日、闰月、当天打卡、已过去的一次性事件、旅行账户删除。
- 通知拒绝/允许、常驻连接关闭、锁屏、划掉最近任务、重启、OEM 省电限制及 Shizuku 未运行/未授权/已授权。

最近任务可见性不等于 OEM 卡片加锁或绝对保活。本次未连接真机，不能声称已经验证长期后台存活；不绕过系统强行停止或用户的关闭选择。
